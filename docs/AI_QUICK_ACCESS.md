# 全局 AI 入口与本地模型配置

## 使用

所有普通业务页面都有 AI 悬浮按钮，默认位于右下角，可以拖动并记住本机位置，调整窗口大小后会保持在屏幕范围内。菜单和小窗随悬浮球定位。菜单提供快捷聊天、完整 AI 会议室、事件分析、全局待确认建议、材料整理和会议记录入口。事件分析会切换到所选 Sprint 并自动滚动到面板；待确认建议复用原顶栏审核入口。菜单上的数字表示项目中待处理提案数。

快捷聊天使用现有 MeetingRoom、coordinateMeetingTurn、AgentProposal 和共享执行器，不维护第二套 Agent 逻辑。选择专业助手后可以直接输入问题，也支持 @成员、@专业助手及 #引用工作。小窗只保留聊天，不显示待确认、纪要和材料导航。消息中的建议审核和材料入口会展开完整会议室，再进行查看和操作；聊天回复不会自行绕过审核修改计划。

小窗与完整会议室共享同一个会话。收起或切换业务页面时，窗口继续挂载，草稿与进行中的回复保留；刷新后从已有记录继续。新建对话才创建新会话，打开菜单不会生成会议。项目切换后不会沿用旧项目会话。普通完整会议室的原有入口与功能保持可用。

## 本机配置

项目根目录 `.env.local` 保存本机配置，分享用的示例模板中 `DEEPSEEK_API_KEY=` 留空。每台机器填入自己的密钥即可；该文件被 Git 忽略，前端不会读取或打包密钥，也不要给变量加 VITE_ 前缀。

服务地址与四个模型字段沿用现有项目模板：日常查询使用快速模型，复杂分析、规划、解释与材料使用对应的高级模型。模板名称只是当前项目的预设；如果账号不支持，请填写服务商实际提供的模型名称。其他 OpenAI Chat Completions 兼容服务可修改 MEETING_LLM_BASE_URL。

保存后，从悬浮菜单底部重新检测模型配置。服务端每次读取 `.env.local`；若开发服务器因环境文件变化重启，等待启动完成后再检测。也可访问 `/api/meeting-llm`。`configured:true` 仅代表读到密钥，实际可用性须通过自己的真实请求验证，取决于鉴权、网络、模型权限及额度。

默认只读取项目根目录 `.env`、`.env.local`；不再自动借用另一项目桌面路径中的配置。确需外置配置时可显式设置 SCRUMFLOW_ENV_FILE（兼容原 SUNNYMIND_ENV_FILE）；外置文件优先级低于本项目文件，进程环境变量优先级最高。已有 MEETING_LLM_API_KEY 或 LLM_API_KEY 会优先于 DEEPSEEK_API_KEY，请避免留下不再使用的旧值。

可分享的空白模板位于 `config/meeting.env.example`；不要提交填写过密钥的本机文件。
