# AI 会议课堂演示 · 实施与验收

日期：2026-10-18。项目：ScrumFlow。会议 ID：`meeting-classroom-sprint-v1`。

## 打开方式

在项目目录运行 `npm run dev`，打开 <http://localhost:8443/>，点击顶部 **智能会议演示**。也可以从会议室的 **历史会议** 打开默认置顶的 **Sprint 项目风险与交付决策 · AI 智能会议演示**。

该会议已结束，采用历史只读展示。39 条消息、议程、主持干预、Proposal 审核、执行审计、纪要和文件保存在本地；刷新后继续可用。已准备好的记录与材料不依赖模型服务。

## 建议的 6–8 分钟讲解路线

1. **开场**：展示主持人宣布目标、三阶段议程、参会角色及 30 分钟预算。对话在固定高度内滚动，左右同时查看项目背景与审批结果。
2. **发现风险**：主持人主动指出 Sprint 2 已逾期及 DATA-024 的阻塞，邀请李娜、陈林、王晨及风险 Agent，展示真实依赖传播与延期 1 / 2 天的同基线模拟。
3. **语义纠偏**：展示“判断有误”“继续讨论”“返回议程”三种反馈。成员反对错误纠偏，主持人撤回；主题色和动画被移至停车场。
4. **审核执行**：比较保留责任人的方案 A 与换人赶工的方案 B。查看逐项审核、执行前条件、写回结果及审计；展开拒绝原因。
5. **会议收尾**：展示黄色提醒、红色超时提醒、未解决事项与责任人。记录时间线为 32 分钟，超出 30 分钟预算 2 分钟，不代表真实发声时长。
6. **会议纪要 → 查看会议洞察**：展示正式摘要、7 项决策责任清单、议程计划/记录用时、角色占比、主持干预、决策漏斗、行动状态及可展开审计。
7. **会议材料**：预览 Word、WBS、依赖图与冻结甘特图，最后下载成果 ZIP。

## 场景与一致性

会议基于初始化时实际项目的 Sprint 2、US024、US025、DATA-024、真实成员和登记依赖建立独立快照。没有将已过期 Sprint 伪装为仍有交付窗口；区分名义剩余容量和按日历计算的剩余窗口。新增日期属于恢复计划，不宣称原 Sprint 按时交付。

合并后的完整演示项目 `scrumflow-comprehensive-demo` 使用了新的任务编号，因此课堂会议改用明确标注的「ScrumFlow 课堂会议独立示例」快照，保留原 US024 / DATA-024 的录制场景。页面会提示这些任务与成员不代表当前项目；完整演示项目的 Release、燃尽图、任务、风险及审批数据均保留原样。原 `scrumflow-ai` 项目仍从自身项目快照建立课堂会议。

## 复用与隔离

- `createProjectStore(snapshot)` 复用相同 Zustand Actions、Proposal 预检和执行器，在独立内存 Store 运行，关闭持久化与 hydration。修正依赖和讨论结果查询中对全局 Store 的引用，改为查询当前 Store。
- 主 Store 只保存演示会话、消息与材料资产。沙盒 Proposal、业务修改和审计只存在于 `outcomeSnapshot`，不进入正式 Proposal、任务、风险、排期、依赖或讨论集合。
- 历史读取和材料生成使用冻结快照。演示分支不叠加正式项目后续变更，甘特图从冻结任务生成，不截取当前正式页面。材料没有正式业务实体关联。
- 初次自动准备后幂等复用；手动取消置顶不会在刷新时被重新置顶。多条置顶按最近置顶时间在前，普通会议按创建时间倒序，ID 作为稳定兜底。
- 正常会议保留实时、语音、审核与材料流程；演示历史关闭输入和执行按钮。材料整理失败可重试，切换项目/演示快照时停止回写旧准备状态。
- 顶部菜单、历史/更多菜单、Gantt 导出菜单使用统一短暂浮层交互：再次点击切换、外部点击关闭、Esc 关闭与焦点返回、互斥展开；模态编辑面板不加入该关闭机制。

## 材料

沿用材料整理与本地资产管线，保存 7 类、19 个文件：正式纪要、Scrum 智能会议报告、WBS、风险清单、依赖图、恢复计划甘特图、变更摘要。格式包括 DOCX / Markdown / HTML、XLSX、PNG / SVG / Mermaid，支持预览、下载与 ZIP。

页面统计与报告复用同一统计函数。Word 保存摘要、决策/责任/审核/审计表；Scrum 报告另含量化统计与口径表。甘特图明确标记沙盒恢复计划，保留任务状态、负责人和日期。

## 演示记录的边界

成员发言、主持语义事件及人工审核动作是明确标记的预设记录，不代表这次实际进行了实时模型推理、ASR 或人工点击。风险/依赖与容量数据来自现有程序，Proposal 确实经相同执行器在沙盒完成写回，材料是实际生成的文件。课堂主要展示该历史的完整链路；新的自由讨论与实时语音仍使用原有服务，本轮没有通过付费调用重新验收。
