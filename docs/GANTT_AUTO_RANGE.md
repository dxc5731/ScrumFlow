# 甘特图自动日期范围

甘特图按当前筛选及折叠后实际显示的 Story、Task、Subtask 条形计算最早开始日期，左边界始终设为该日期前三天。Epic 在当前甘特图中只是分组标题，不会用其包含隐藏故事的日期拉宽当前范围；没有显示条形时保留原范围。

拖动和调整开始日期时使用实时排期预览计算边界。最早节点左移会立即向左扩展，右移会立即向右收缩；鼠标移动仍按拖动起点累计计算，坐标变化不会反过来改变本次拖动量。靠近左边缘时持续平移，即使尚无可滚动日期也会继续生成更早的范围。预览不会写入业务日期，松手后才走现有排期校验和保存。

切换 Sprint、Release 或成员筛选时重新定位，图片导出采用相同范围规则。右边界至少覆盖所有显示条形结束后的三天，并保留已有的右侧范围。

当前示例项目及初始化、重置演示数据的基准统一调整到 2026-10-10 至 2026-10-31：按先后和并行工作错开 Story、Task 与 Subtask，Epic 汇总子项日期，Sprint 与 Release 的计划日期同步调整。状态、成员、归属、资产、会议和既有历史保留，历史燃尽快照不会按新排期改写。旧数据备份为 output/schedule-adjustment/project-before.json。
