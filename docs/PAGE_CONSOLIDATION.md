# 项目、验收和风险入口合并

本轮只合并这三处页面，不修改需求层级、Release 发布规则、任务流转、燃尽统计或现有项目数据。

- 主导航“项目”下包含概况、基本资料和项目用例图。概况只保留基本规模、日期和可直接进入处理的待办；删除原重复进度卡片、只读风险摘要与变更摘要。项目资料、空白项目创建和会议入口继续保留。
- Sprint 增加“迭代进度 / 待验收 / 风险管理”标签页。“待验收”复用原故事验收面板，继续支持成果核对、验收通过、退回重开、验收记录；列表和计数统一使用所选 Sprint。
- Sprint 和 Release 都可以打开风险管理面板。范围覆盖当前迭代或版本下关联 Story、Task 和 Sprint 的登记风险；Release 同时包含尚未排入 Sprint 的版本故事。面板保留登记、编辑、状态、删除、负责人、影响、应对措施和对象跳转，并支持原地“查看全部 / 返回本范围”。
- 旧 overview、project-use-case、settings、acceptance、risks 页面标识继续兼容；恢复旧工作区或内部跳转时会进入对应的新容器，不会出现空页面。只有导航布局和可选工作区标签字段变化，无数据结构迁移。

验证包括合并后的导航、基本资料和用例标签、Sprint 切换、实际验收记录追加、风险创建编辑删除及跨范围筛选，另通过浏览器在隔离数据上检查布局与交互。
